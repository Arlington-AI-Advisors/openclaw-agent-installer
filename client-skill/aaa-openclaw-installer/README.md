# Arlington AI Advisors: OpenClaw Installer

This package is for approved AAA clients. Do not share it.

## What's inside

- `install.sh`: the AAA OpenClaw installer
- `skills.git`: the studio skills the installer sets up (no GitHub access needed)
- `SKILL.md`: a Claude Code skill that walks you through the install
- `VERSION.txt`: the version you downloaded

## How to use it

1. Unzip this folder into your home folder, so it ends up at `~/aaa-openclaw-installer`.
2. Open Claude Code in that folder.
3. Tell Claude Code: `Use the aaa-openclaw-installer skill and help me install OpenClaw.`
4. Claude Code checks your computer, then gives you commands to paste into your own Terminal app. You run each one and paste the result back.
5. It runs a preview first. Nothing is installed until you approve.

You can stop at any time with Ctrl+C.
